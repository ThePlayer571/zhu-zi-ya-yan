# 诸子雅言 · 闯关试炼

## 如何添加关卡

编辑 `public/challenges/index.json` 文件，在 `levels` 数组中添加新的关卡对象。

### 关卡格式

```json
{
  "id": "echo-input",
  "title": "回响之问",
  "description": "程序接收一个输入，原样输出之。",
  "difficultyGroup": "开蒙",
  "category": "入门",
  "testCases": [
    {
      "inputs": ["春日"],
      "expectedOutput": "春日"
    },
    {
      "inputs": ["秋月"],
      "expectedOutput": "秋月"
    }
  ],
  "hint": "用「问」语句读取输入，再用「曰」输出。",
  "templateCode": "《试炼》\n  \n",
  "groupOrder": 2
}
```

### 字段说明

| 字段                | 类型     | 必填 | 说明                                                         |
|---------------------|----------|------|--------------------------------------------------------------|
| `id`                | string   | 是   | 关卡唯一标识符，用于 URL 路由（如 `/challenge/echo-input`）    |
| `title`             | string   | 是   | 关卡标题，显示在选择页和题目页                                |
| `description`       | string   | 是   | 题目描述，支持 `\n` 换行                                     |
| `difficultyGroup`   | string   | 是   | 难度组别：`"开蒙"`（教程）、`"院试"`（进阶）、`"殿试"`（综合）|
| `category`          | string   | 是   | 分类标签（如 "入门"、"算术"、"字符串"、"列表"、"控制流"）     |
| `testCases`         | array    | 是   | 测试用例列表（见下方说明）                                    |
| `hint`              | string   | 否   | 提示文本，在用户卡关时显示                                    |
| `templateCode`      | string   | 否   | 预填充到代码编辑器的模板代码                                  |
| `groupOrder`        | number   | 否   | 组内排序权重，越小越靠前                                      |

### 测试用例说明

每个测试用例是一个对象，包含：

| 字段             | 类型     | 必填 | 说明                                                     |
|------------------|----------|------|----------------------------------------------------------|
| `inputs`         | string[] | 否   | 按顺序提供给程序的输入列表（程序调用一次「问」消费一个输入）|
| `expectedOutput` | string   | 是   | 程序应输出的文本（精确匹配，程序所有输出拼接后比对）       |

#### 测试用例运行方式

每个测试用例会**独立运行一次**程序。对于含 `inputs` 的用例，后端使用 `POST /api/run-test` 端点，将 `inputs` 数组按顺序注入程序的输入语句（「问」/「询」/「质」/「听」/「闻」）。

示例：若程序为 `问名子。名子曰。`，测试用例 `{"inputs": ["李白"], "expectedOutput": "李白"}`，则运行时程序读取输入得到「李白」，输出「李白」，与期望匹配通过。

若不提供 `inputs`（或为空数组），程序运行时输入语句将收到空字符串。

#### 多个测试用例

一个关卡可以有多个测试用例，程序会分别对每个用例运行一次。所有用例通过才算通关。

```json
{
  "testCases": [
    { "inputs": ["三", "五"], "expectedOutput": "八" },
    { "inputs": ["十", "二"], "expectedOutput": "十二" },
    { "inputs": ["零", "七"], "expectedOutput": "七" }
  ]
}
```

### 难度组别与头衔

诸子雅言共有三个难度组别，每个组别对应一个头衔。通关某组别的全部关卡后，可获得相应头衔。

| 组别   | 说明   | 头衔         | 头衔说明                     |
|--------|--------|--------------|------------------------------|
| `开蒙` | 教程   | **童生**     | 通晓文言基础，可谓童生。     |
| `院试` | 进阶   | **秀才**     | 博学于文，可谓秀才。         |
| `殿试` | 综合   | **进士**     | 学而优则仕，可谓进士。       |

头衔会显示在选关界面的左侧难度选择栏中。已获得的头衔以玉色高亮；未获得者以灰色显示并附进度（如 "2/4"）。

### 难度标签（旧版兼容）

旧版使用的英文难度标签 (`easy`/`medium`/`hard`) 已不再使用，请使用 `difficultyGroup` 字段代替。

### 排序

关卡在各自难度组内按 `groupOrder` 字段升序排列。`groupOrder` 相同的关卡按在 `index.json` 中的出现顺序排列。建议每隔 10 编号以便插入新关卡（如 10、20、30…）。
