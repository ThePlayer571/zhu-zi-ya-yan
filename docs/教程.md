# 诸子雅言

诸子雅言是一门春秋时期古文风的深奥编程语言。使用文言文自然语言编程。

设计哲学：

1. 句读，立章法之基。
2. 尚文采，容万殊之变。
3. 撰码如属文，自然成章。
4. 容错不报，静默归无。

这是一门解释型语言，解释器由 python 编写。

> 下文使用 python 代码描述功能，不代表最终解释结果为对应 python 代码。

## 语法介绍

程序只允许包含中文全角字符，使用其余字符认为是未定义行为。

### 语句

诸子雅言以语句作为基本可执行单元。

每条语句必须以`终止符`结尾。终止符包括`。`、`？`、`！`。

语句内部可以用`断句符`进行断句。断句符包括`，`、`、`。 被断句符分开的每一部分称为`句`。

`终止符`和`断句符`统称为`句读`。

语句可以是无意义的。如果语句无法解析出含义，认为这是一条`文学性语句`。

如果一个句中不包含任何可解析的类型，认为这是一条`文学性句`。

### 变量定义

所有变量名均须以`子`结尾。

编译器从语句开头逐字检索，遇到`子`时，收集从当前句开头到`子`的所有字符，认为这是变量名。 若当前作用域内不存在同名变量，则认为该语句为变量定义语句。

收集变量名之后，编译器将判断初始化类型。目前支持以下五种类型：

- 字符串
- 非负整数
- 非负浮点数
- 布尔值
- 列表

---

##### 字符串

字符串使用以下关键字定义：

- `曰`、`云`独立使用——人物说话，最为简洁
- `文`搭配`作`、`书`——人物撰文
- `言`、`语`搭配`述`——人物述言
- `诗`搭配`作`、`吟`——人物作诗吟诗

可表示为：

```
(.*<句读>)?<变量名>.*(曰|云)<字符串内容><句读>?.*<终止符>
(.*<句读>)?<变量名>.*文.*(作|书)<字符串内容><句读>?.*<终止符>
(.*<句读>)?<变量名>.*(言|语).*述<字符串内容><句读>?.*<终止符>
(.*<句读>)?<变量名>.*诗.*(作|吟)<字符串内容><句读>?.*<终止符>
```

字符串内容不得包含任何句读。

示例：

```text
孔子曰有朋自远方来不亦乐乎。
```

```python
孔子 = "有朋自远方来不亦乐乎"
```

示例：

```text
孟子云舍生而取义者，善哉。
```

```python
孟子 = "舍生而取义者"
```

示例：

```text
太白子，号青莲，诗仙也，醉吟将进酒杯莫停。
```

```python
太白子 = "将进酒杯莫停"
```

##### 非负整数

非负整数使用以下关键字定义：

- `数`——意为"数目为..."

可表示为：

```
(.*<句读>)?<变量名>.*数<非负整数>.*<终止符>
```

> 推荐在 `数` 之前加入动词短语，如 `将兵`、`持`等，描述人物行为。
> 此类修饰内容不参与解析，仅作文学表达。

非负整数字面量采用古文描述整数的方式表达，具体格式见[附录：非负整数书写规则](#非负整数书写规则)。

编译器识别到`数`后开始收集字符，遇见第一个不属于非负整数字面量的字符停止收集。

非负整数字面量的字符集合见[附录：非负整数字面量](#非负整数字面量)。

示例：

```text
孙子，练兵数三千。
```

```python
孙子 = 3000
```

示例：

```text
祖冲之子，记数三百。
```

```python
祖冲之子 = 300
```

示例：

```text
孔丘子，教授门生数七十有二也。
```

```python
孔丘子 = 72
```

---

##### 非负浮点数

非负浮点数使用以下关键字定义：

- `度`——测量，人物度量某物
- `量`——计量，人物称量某物

可表示为：

```
(.*<句读>)?<变量名>.*(度|量).*(曰)<非负浮点数>.*<终止符>
```

> 推荐在 `度`/`量` 之后加入度量对象，如 `圆周`、`酒`、`金` 等，描述人物度量之物。

非负浮点数字面量采用古文描述小数的方式表达，具体格式见[附录：非负浮点数字面量](#非负浮点数字面量)。

编译器识别到定义关键字后开始收集字符，遇见第一个不属于浮点数字面量的字符停止收集。

浮点数字面量的完整字符集合见[附录：非负浮点数字面量](#非负浮点数字面量)。

示例：

```text
冲之子，度圆周曰三又一秒四厘一忽六微。
```

```python
冲之子 = 3.1416
```

示例：

```text
酒正子，量酒曰一十二又五秒。
```

```python
酒正子 = 12.5
```

示例：

```text
衡子，度金曰百又三。
```

```python
衡子 = 103.0
```

##### 布尔值

布尔值使用以下关键字定义：

- `辩`、`判`、`断`、`决`、`是非`搭配`曰`、`为`——人物判断某事

可表示为：

```
(.*<句读>)?<变量名>.*(辩|判|断|决|是非).*(曰|为)(是|然|否|非).*<终止符>
```

> 推荐在判断关键字后加入判断对象，描述人物判断之事。

布尔值字面量如下：

| 字面量 | 对应值  |
|--------|---------|
| 是、然 | `True`  |
| 否、非 | `False` |

示例：

```text
孟子，辩曰是。
```

```python
孟子 = True
```

示例：

```text
天晴子立于皋上，断雨者曰非。
```

```python
天晴子 = False
```

---

以上四种类型统称为 **基础类型**。

##### 列表

列表使用两个字组合成的关键字定义，第一字标识动作，第二字标识元素类型。

动作字：

- `举`——枚举、罗列
- `列`——排列

元素类型标识字：

- `言`——字符串元素
- `数`——整数元素
- `度`——浮点数元素
- `判`——布尔元素

可表示为：

```
(.*<句读>)?<变量名>.*(举|列)(言|数|度|判)<值>(、<值>)*<非、句读>.*<终止符>
```

编译器识别到定义关键字后开始收集元素，以`、`划分元素；遇见其他句读时停止收集。

想定义空列表，需要写完整的列表语法，但不提供任何元素。

示例：

```text
门生子，举言颜回、子路、子贡。
```

```python
门生子 = ["颜回", "子路", "子贡"]
```

示例：

```text
张衡子，尝举数一、三、五、七、九。
```

```python
张衡子 = [1, 3, 5, 7, 9]
```

示例：

```text
温酒子，列度六又五秒、八又三秒。
```

```python
温酒子 = [6.5, 8.3]
```

示例：

```text
决疑子，举判，是、非、是、非。
```

```python
决疑子 = []
```

##### None

当定义语句解析出现错误时，编译器将该变量初始化为 `None`。

`None` 是一个单独的类型，任何对 `None` 的操作都会静默无效。

> 类似地，任何语句运行时若发生错误，会将操作目标变量置为 `None`，绝不抛出异常。

### 值返回表达式

提出 `值返回表达式` 这个概念，是为了简化后续的说明。

值返回表达式是一个无副作用的、有返回值的表达式。比如：

```text
夫子取颜回子。
夫子取列子其二。
```

其中的`颜回子`和`列子其二`都是值返回表达式。

所有可以作为值返回表达式的代码如下：

- 已定义的变量名
- 列表的索引访问

> 注意：字面量不是值返回表达式。

### 运算符

运算符用于变量之间的运算。

编译器从语句开头逐字检索，遇到`子`时，收集从当前句开头到`子`的所有字符，认为这是变量名。 若当前作用域内已存在同名变量，则认为该语句为运算语句。

收集变量名之后，编译器将判断运算符关键字，确定运算类型。

运算符分为三类：赋值、计算赋值、判零与判正。

> 注：若运算使 `非负整数` 或 `非负浮点数` 类型变量的值变为负数，则自动将该值置为 `0`。
> 详见[负数截断规则](#负数截断规则)。

---

##### 赋值

赋值运算符将右侧的值赋予左侧变量，语义与 Python `=` 基本一致。

唯一不同的是，列表赋值会拷贝一份列表。

关键字：`取`、`为`、`命`、`效`。

可表示为：

```
(.*<句读>)?<变量名>.*(取|为|命|效)<值返回表达式>.*<终止符>
```

示例：

```text
夫子取颜回子。
```

```python
夫子 = 颜回子
```

示例：

```text
翌日，国君子命仁德子哉，众士欢也。
```

```python
国君子 = 仁德子
```

---

#### 计算赋值

计算赋值运算符对变量进行运算，然后将结果赋回原变量。

计算赋值均为二元运算，右侧须为值返回表达式。

计算赋值要求两侧的变量类型一致。若类型不一致，目标变量被置为 `None`。

可表示为：

```
(.*<句读>)?<变量名>.*<运算符关键字><值返回表达式>.*<终止符>
```

各运算符关键字如下：

| 运算符 | 关键字     |
|--------|------------|
| `+=`   | 益、并、合 |
| `-=`   | 损、消、差 |
| `*=`   | 倍、因、积 |
| `/=`   | 分、约、商 |
| `%=`   | 余         |

所有运算皆会映射成 Python 的运算。

##### +=

关键字：`益`、`并`、`合`。

```text
孙子益兵数子。
```

```python
孙子 += 兵数子
```

```text
仓廪子并新谷子。
```

```python
仓廪子 += 新谷子
```

##### -=

关键字：`损`、`消`、`差`。

```text
府库子损开支子。
```

```python
府库子 -= 开支子
```

```text
万金子消酒钱子。
```

```python
万金子 -= 酒钱子
```

##### *=

关键字：`倍`、`因`、`积`。

```text
田子倍亩数子。
```

```python
田子 *= 亩数子
```

```text
甲兵子因倍数子。
```

```python
甲兵子 *= 倍数子
```

##### /=

关键字：`分`、`约`、`商`。

```text
粮子分人口子。
```

```python
粮子 /= 人口子
```

##### %=

关键字：`余`

```text
甲子余除数子。
```

```python
甲子 %= 除数子
```

#### 判零

`为零` 运算符判断变量是否为零，将布尔结果赋回原变量。

关键字：`虚`、`空`、`阴`。

可表示为：

```
(.*<句读>)?<变量名>.*(虚|空).*<终止符>
```

对于各类型的判定规则如下：

| 类型                     | 为零条件         |
|--------------------------|------------------|
| `非负整数`、`非负浮点数` | 值等于 `0`       |
| `布尔值`                 | 值为 `False`     |
| `字符串`                 | 字符串长度为 `0` |
| `列表`                   | `len()` 为 `0`   |
| `None`                   | 始终为 `True`    |

示例：

```text
甲兵子虚。
```

```python
甲兵子 = (甲兵子 == 0)
```

示例：

```text
言子空。
```

```python
言子 = (len(言子) == 0)
```

---

#### 判正

`为正` 运算符判断变量是否为正数，将布尔结果赋回原变量。

关键字：`正`、`善`、`阳`。

可表示为：

```
(.*<句读>)?<变量名>.*正.*<终止符>
```

对于各类型的判定规则如下：

| 类型                     | 为正条件           |
|--------------------------|--------------------|
| `非负整数`、`非负浮点数` | 值大于 `0`         |
| `布尔值`                 | 值为 `True`        |
| `字符串`                 | 字符串长度大于 `0` |
| `列表`                   | `len()` 大于 `0`   |
| `None`                   | 始终为 `False`     |

示例：

```text
收成子正。
```

```python
收成子 = (收成子 > 0)
```

示例：

```text
门生子善。
```

```python
门生子 = (len(门生子) > 0)
```

---

#### 负数截断规则

若赋值或计算赋值的结果使 `非负整数` 或 `非负浮点数` 类型变量的值变为负数，则自动将该值截断为 `0`。

> 此规则意在贴合"非负"的设计基调。

> 此外，若运算不支持（如对字符串执行 `-=`、对布尔值执行 `*=` 等），目标变量将被置为 `None`。

示例：

```text
府库子损开支子。
```

```python
# 假设 府库子 = 100, 开支子 = 150
府库子 -= 开支子  # 结果为 -50
府库子 = 0  # 截断为 0
```

### 列表

列表从1开始索引，索引值为非负整数。

支持以下操作：

- 索引访问
- 索引修改
- 追加元素
- 删除尾部元素
- 删除头部元素

---

##### 索引访问

通过索引访问列表元素，返回对应位置的元素。

关键字：`之`、`其`。

可表示为：

```
<变量名>(之|其)<非负整数索引>
```

这是一个值返回表达式。

索引访问只能使用字面量索引值，不能使用变量索引。

示例：

```text
夫子取门生子其一。
```

```python
夫子 = 门生子[0]  # 列表从1开始索引
```

---

##### 索引修改

通过索引修改列表指定位置的元素。

关键字：`易之`、`易其`。

关键字：`曰`、`为`。

可表示为：

```
(.*<句读>)?<变量名>.*(易之|易其)<非负整数索引>.*(曰|为)<值返回表达式>.*<终止符>
```

索引修改只能使用字面量索引值，不能使用变量索引。

若索引越界或类型不匹配，列表变量置为 `None`。

示例：

```text
门生子易其二曰颜渊子。
```

```python
门生子[1] = 颜渊子  # 列表从1开始索引
```

---

##### 追加元素

向列表末尾追加新元素。

关键字：`接`、`增`。

可表示为：

```
(.*<句读>)?<变量名>.*(接|增)<值返回表达式>.*<终止符>
```

示例：

```text
门生子接颜渊子。
```

```python
门生子.append(颜渊子)
```

示例：

```text
门生子接门弟子其二。
```

```python
门生子.append(门第子[1])
```

若追加元素的类型与列表元素类型不匹配，列表变量置为 `None`。

---

##### 删除尾部元素

删除列表的最后一个元素。

关键字：`削`、`刈`。

可表示为：

```
(.*<句读>)?<变量名>.*(削|刈).*<终止符>
```

示例：

```text
门生子削。
```

```python
门生子.pop()
```

若列表为空，列表变量置为 `None`。

---

##### 删除头部元素

删除列表的第一个元素。

关键字：`斩`、`刎`。

可表示为：

```
(.*<句读>)?<变量名>.*(斩|刎).*<终止符>
```

示例：

```text
门生子斩。
```

```python
门生子.pop(0)
```

若列表为空，列表变量置为 `None`。

### 函数

函数是诸子雅言中的可复用执行单元。每个函数对应一个篇章，以书名号 `《》` 标识。

函数具有以下特性：

- **无参数、无返回值**——函数之间通过全局变量交互（详见[项目结构](#项目结构)）
- **允许空函数**——函数体内可以不含任何语句

> 解释器解析书名号的优先级最高，因此书名号不能包括在其他语法中（比如注释、字符串初始化等）。

---

##### 函数定义

函数定义以 `《函数名》` 开头，函数名不得包含句读。函数名之后直至下一个函数定义或文件结尾，均为函数体。

可表示为：

```
《<函数名>》<语句>*
```

示例：

```text
《学而》
孔夫子曰学而时习之，不亦说乎。
```

```python
def 学而():
    孔夫子 = "学而时习之，不亦说乎"
```

示例：

```text
《问仁》
颜回子问曰仁。夫子曰克己复礼为仁。
```

```python
def 问仁():
    颜回子 = "仁"
    夫子 = "克己复礼为仁"
```

示例：

```text
《无名》
```

```python
def 无名():
    pass
```

---

##### 函数调用

函数调用以变量为主体，使用调用关键字后接目标函数名。

关键字：`行`、`践`、`施`、`修`、`用`。

可表示为：

```
(.*<句读>)?<变量名>.*(行|践|施|修|用)《<函数名>》.*<终止符>
```

> 注：调用语句中的变量名仅作为文学修饰，不影响函数执行。函数无参数、无返回值，故变量不传入参数也不接收返回值。

> 若目标函数不存在，静默跳过，不产生任何效果。

示例：

```text
孔夫子行《学而》。
```

```python
学而()
```

示例：

```text
翌日，子路践《问仁》，众弟子恭听也。
```

```python
问仁()
```

### 注释

诸子雅言用于在源码中撰写注解，解释器会忽略注释内容。

诸子雅言采用古文注疏风格的注释系统，每条注释由 **注释定义**和 **注解**两部分组成。
注释定义写在语句之中，注解应该写在函数结尾处（即下一个函数定义之前或文件结尾之前）。

注解仅作用于当前函数。

---

##### 注释定义

注释定义用于在语句中标记一个待注解的位置。

语法：

```
【<注释标识符>】
```

- 注释标识符可以是任意内容，但不得包含全角冒号 `：`、句读和书名号。
- 注释定义可以位于语句中的任意位置，解释器在解析时会将其忽略。
- 同一函数内，注释标识符不得重复。

---

##### 注解

注解写在函数体的末尾，对注释定义进行补充说明。

语法：

```
【<注释标识符>：<注解内容>】
```

- `：` 为注解关键字，分隔标识符与注解内容。
- 注解内容可以是任意文字，但不得包含 `】`和书名号。（可以包含句读）

出现在函数体中间的注解属于未定义行为，可能导致解释器无法正确解析。

---

##### 示例

```text
《学而》
孔夫子【壹】曰学而时习之【贰】，不亦说乎。
【壹：孔子，名丘，字仲尼，春秋时期思想家。】
【贰：习，温习、实践也。】
```

```python
def 学而():
    孔夫子 = "学而时习之，不亦说乎"
```

### 项目结构

诸子雅言目前仅支持单文件解释。

一个诸子雅言源文件如同一卷书，由书名和若干篇章组成。

##### 篇章模型

- **书名函数**：源文件的第一个函数。该函数是程序的入口。
- **篇章函数**：书名之后定义的每个函数，是书中的各篇章。

程序运行时，会调用书名函数一次。

##### 变量作用域

诸子雅言的变量作用域遵循以下规则：

- 在书名函数中定义的变量，均为全局变量，可在所有函数中调用。
- 篇章函数中定义的变量，为局部变量，仅可在当前函数中调用。

##### 示例

```text
《论语》
孔夫子曰学而时习之。孔夫子行《学而》。

《学而》
曾子曰吾日三省吾身。孔夫子效曾子。
```

```python
# 顶层初始化（全局变量）
孔夫子 = None


def 论语():
    global 孔夫子
    孔夫子 = "学而时习之"
    学而()


def 学而():
    global 孔夫子
    曾子 = "吾日三省吾身"
    孔夫子 = 曾子


# 入口
论语()
```

### 控制流 - if

if 控制流用于根据条件执行函数。

与其他语言不同的是，诸子雅言的 if 是一种语句——它遵循语句的规则，以终止符结尾，内部可用断句符断句。

if 允许传入一个变量，该变量必须为布尔值。if 内只允许包含一个函数调用。

编译器从语句开头逐字检索。若在遇到 `子` 之前先遇到了 if 关键字，则将该语句识别为 if 语句，不再匹配变量定义或运算语句。

##### 语法

if关键字：`若`、`倘`、`倘`、`使`。

条件关键字：`则`、`即`。

可表示为：

```
.*(若|倘|苟|使)<已定义的布尔值变量名>.*(则|即)(行|践|施|修|用)《<函数名>》.*<终止符>
```

运行时，若条件变量的值为 `True`，则调用指定函数； 否则跳过该语句。

如果条件变量不是布尔类型，静默跳过。

##### 示例

```text
若雨落子则行《撑伞》。
```

```python
if 雨落子:
    撑伞()
```

```text
荀卿子辩曰是。翌日，倘荀卿子即践《论礼》。
```

```python
荀卿子 = True
if 荀卿子:
    论礼()
```

```text
城门子，守军断曰非。苟城门子则用《警备》，众将士严阵也。
```

```python
城门子 = False
if 城门子:
    警备()
```

```text
使仁德子则施《赏贤》。
```

```python
if 仁德子:
    赏贤()
```

### 输入输出

输入输出用于程序与外界交互。输出将变量值展示于外界，输入从外界读取数据存入变量。

编译器从语句开头逐字检索，遇到`子`时，收集从当前句开头到`子`的所有字符，认为这是变量名。 若当前作用域内已存在同名变量，则继续匹配输入输出关键字确定操作类型。

---

##### 输出

输出将变量的值展示于外界。

关键字：`曰`、`言`、`谓`、`宣`、`吟`。

> `曰` 也用于字符串定义。编译器通过变量是否已存在来区分。

可表示为：

```
(.*<句读>)?<变量名>.*(曰|言|谓|宣|吟).*<终止符>
```

示例：

```text
孔子曰。
```

```python
print(孔子)
```

示例：

```text
夫子言其名。
```

```python
print(夫子)
```

示例：

```text
诗仙子醉吟其诗，快哉快哉。
```

```python
print(太史公)
```

---

##### 输入

输入从外界读取一行数据，以字符串类型存入变量。

关键字：`问`、`询`、`质`、`听`、`闻`。

其中 `问`、`询`、`质` 可在关键字后紧接一个字符串字面量，表示询问的内容。该字符串内容会在等待输入前输出，作为提示信息。`听`、`闻`
不支持此用法。

可表示为：

```
(.*<句读>)?<变量名>.*(问|询|质)(<字符串内容>)?.*<终止符>
(.*<句读>)?<变量名>.*(听|闻).*<终止符>
```

> 字符串内容不得包含任何句读。
> 推荐使用 `？` 作为输入语句的终止符，模拟文言中发问的语气。

示例：

```text
路子问。
```

```python
路子 = input()
```

示例：

```text
路子问君子之道何如？
```

```python
print("君子之道何如")
路子 = input()
```

示例：

```text
司农子质今岁收成几何？
```

```python
print("今岁收成几何")
司农子 = input()
```

《问政》
孔夫子曰为政以德。路子，夫子门人也。路子问敢问为政何先？孔夫子言其理。

def 问政():

#### 非负整数书写规则

非负整数字面量采用文言记数法，由以下成分构成。

**数字字**

| 字 | 值 |
|----|----|
| 一 | 1  |
| 二 | 2  |
| 三 | 3  |
| 四 | 4  |
| 五 | 5  |
| 六 | 6  |
| 七 | 7  |
| 八 | 8  |
| 九 | 9  |

**进位字**

| 字 | 权值 |
|----|------|
| 十 | 10¹  |
| 百 | 10²  |
| 千 | 10³  |
| 万 | 10⁴  |
| 亿 | 10⁸  |
| 兆 | 10¹² |

**连接字**：`有`、`又`。分隔独立数值，表示加法。

**占位字**：`零`。显式补零，语义与 `有` 等效。

##### 组合规则

1. 数字字置于进位字 **之前**表示乘法，置于 **之后**表示加法。
2. 进位字前若无数字字，默认系数为 `一`（1）。
3. 以 `兆`、`亿`、`万` 为节，由高至低排列；各节内部遵循上述规则，节间值相加。
4. 连接字 `有` / `又` 分隔的各部分独立求值后相加。
5. `零` 可用于显式占位，与 `有` 等效。

##### 示例

| 写法                               | 值                |
|------------------------------------|-------------------|
| 三十                               | 30                |
| 十有五                             | 15                |
| 百又三                             | 103               |
| 三千五百                           | 3,500             |
| 一万二千三百四十五                 | 12,345            |
| 一亿二千三百四十五万六千七百八十九 | 123,456,789       |
| 五兆三千亿                         | 5,300,000,000,000 |

#### 非负整数字面量

非负整数字面量由以下字符组成：

| 类别 | 字符                       |
|------|----------------------------|
| 数字 | 一 二 三 四 五 六 七 八 九 |
| 进位 | 十 百 千 万 亿 兆          |
| 连接 | 有 又                      |
| 占位 | 零                         |

编译器在收集非负整数字面量时，连续读入上述字符，直至遇到第一个不属于该集合的字符为止。

#### 非负浮点数字面量

非负浮点数字面量包含[非负整数字面量](#非负整数字面量)的全部字符，此外 `又` 复用为小数点，分隔整数与小数部分，并增加以下小数位字：

| 类别   | 字符 | 含义 |
|--------|------|------|
| 十分位 | 秒   | 10⁻¹ |
| 百分位 | 厘   | 10⁻² |
| 千分位 | 忽   | 10⁻³ |
| 万分位 | 微   | 10⁻⁴ |

格式：

```text
<非负整数>又<n 秒><m 厘><x 忽><y 微>
```

各小数位均可省略，但出现时必须按 `秒`、`厘`、`忽`、`微` 的顺序。

编译器在收集非负浮点数字面量时，连续读入上述字符，直至遇到第一个不属于该集合的字符为止。
